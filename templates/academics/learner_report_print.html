How to read this report
  • Remark-only subjects take a remark once per term and no marks, so they are not part of the average or position.
  • Only marks that have been entered and approved are included; assessments not yet marked are left out, never counted as zero. Each subject mark is the weighted average of the assessments marked so far, with the weights shown under each assessment rescaled over those marked.
  • Grades: {% for g, r, l in scale %}{{ g }} {{ r }} ({{ l }}){% if not forloop.last %} · {% endif %}{% endfor %}. Pass mark {{ pass_mark }}% (grade C).
